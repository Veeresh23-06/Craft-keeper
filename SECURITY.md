# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Craft Keeper is committed to responsible handling of software vulnerabilities and data privacy risks.

If you discover a security vulnerability (such as unintended API key exposure, memory leakage, or arbitrary command execution via media parsing):
1. **Do not create a public issue on GitHub.**
2. Send an email to the project maintainers or open a private advisory via GitHub Security Advisories.
3. Please include reproduction steps, your operating system, and the active `CRAFT_BACKEND` mode.

We will acknowledge receipt within 48 hours and work with you to release a patch.

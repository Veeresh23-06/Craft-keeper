# Sample Data for Craft Keeper

This directory contains sample output and guidance on testing videos.

## Sample Output
- `sample_guide.json`: A verified Craft Keeper output representing a traditional recipe ("Traditional Mysore Pak"). This is used by the `mock` backend to allow end-to-end testing and demo execution without network connectivity or GPU hardware.

## Testing with Real Videos
For copyright and privacy reasons, video files are not tracked in this repository.

To test Craft Keeper with real videos:
1. Record a short (1-3 minute) video of yourself or someone who has explicitly consented, demonstrating a traditional recipe or craft (e.g., origami, braiding, cooking, pottery).
2. Or use Creative Commons / public domain instructional videos available on [Wikimedia Commons](https://commons.wikimedia.org/) or [Internet Archive](https://archive.org/).
3. Ensure the video format is `.mp4`, `.mov`, or `.webm` and under 100 MB.
